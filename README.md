# ClubApp — Parcial 1 (Aplicaciones Móviles)

Aplicación Android para socios de un club social y deportivo. Permite ver el
carnet de socio, las actividades inscriptas y anotarse a próximos eventos.

## Pantalla desarrollada
**Inicio**: muestra los datos del socio, sus actividades inscriptas
y los próximos eventos del club, con la posibilidad de anotarse a un evento
desde un botón.

## Funcionalidad dinámica
Al presionar el botón "Anotarme" en un evento, se agrega dinámicamente
(desde código Java) una tarjeta con los datos de la inscripción al listado
de "Mis Inscripciones Confirmadas".
